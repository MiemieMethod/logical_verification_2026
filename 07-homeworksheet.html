问题 2（5 分 + 1 分附加分）：列表的单子结构

List 可以被视为一个单子（monad），类似于 Option，但具有多个可能的结果。它也类似于 Set，但结果是有序且有限的。以下代码将 List 设置为一个单子。

def bind {α β : Type} : List α → (α → List β) → List β
  | [],      f => []
  | a :: as, f => f a ++ bind as f

def pure {α : Type} (a : α) : List α :=
  [a]
